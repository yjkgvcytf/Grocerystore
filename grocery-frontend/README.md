# GroceryStore Web Frontend

React + TypeScript + TailwindCSS grocery shopping web application.

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Create `.env` file:
```
VITE_API_URL=/api
```

## Features

- Responsive design for mobile and desktop
- Multi-language support (zh/en/ru)
- Dark mode support
- Touch-optimized UI
- Fast hot reload with Vite
